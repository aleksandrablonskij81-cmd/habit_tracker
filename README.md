                             # Habit Tracker

Трекер полезных привычек с Telegram-ботом.

## Технологии

- Python 3.12
- Django 6.0
- Django REST Framework
- PostgreSQL
- Redis
- Celery
- Celery-beat
- Nginx
- Gunicorn
- Docker + Docker Compose
- GitHub Actions (CI/CD)

## Установка (локально, без Docker)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/aleksandrablonskij81-cmd/habit_tracker.git
cd habit_tracker
